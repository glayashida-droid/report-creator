# 数据表 · 限值行自动校验

labels: `ready-for-agent`

## Problem statement

数据表附件目前的「列校验」与「整表数据校验」都要报告员每次手动输入上下限，同一模版反复用时容易漏填、填错，也和表里真实限值脱节。报告员希望把限值写进表内固定的 **限值行**，一点「数据校验」就按表内规则标超限；无该行则不做校验。同时限值行要能进预览、可选进 Word，且导入样品编号时不能盖掉「限值」标记。

## Solution

去掉列头「校验」与「整表数据校验」，合成一个 **数据校验** 按钮。校验时读当前预览快照：若样品列（第 1 列）某行文本为「限值」，则按该行各列（或整行仅一格）的限值表达式比对数据区；提示方式与现有超限红字 / 通过·失败对话框一致。无限值行则按钮低亮不可点。预览始终显示限值行；其旁勾选「报告中显示限值行」（默认不勾、仅本次打开有效、不落盘）控制 Word 是否输出该行。单列整表共用限值时，导出/展示用跨列居中，不改 xlsx。导入样品编号时：除限值行外的表头并成「样品编号」，限值行紧挨其下并保留标记。

## User stories

1. **US-01 合并按钮**：作为报告员，数据表抽屉工具栏只有一个「数据校验」按钮；列头不再出现逐列「校验」；不再出现「整表数据校验」与手动上下限弹窗。
2. **US-02 无限值行不可用**：作为报告员，当前表快照中找不到样品列文本为「限值」的行时，「数据校验」低亮且不可点；我在 Excel 中删掉该行并刷新后，按钮变为不可用。
3. **US-03 有限值行可用**：作为报告员，刷新后快照中存在限值行时，「数据校验」可点；点按后按表内限值自动比对，不再弹出输入框。
4. **US-04 按列限值**：作为报告员，限值行上部分数据列写了表达式、部分为空时，只校验有表达式的列；空列与样品列跳过。
5. **US-05 单格整表限值**：作为报告员，限值行除标记列外只有一格非空表达式时，整表所有数据列共用该表达式（等同旧「整表」一次上下限）。
6. **US-06 区间语法**：作为报告员，限值格写 `a～b`（波浪线，可含负数如 `-5～0`）时，数值满足 `a ≤ v ≤ b` 为合格；不带单位。
7. **US-07 单向开闭**：作为报告员，限值格支持 `大于x` / `>x`（`v > x`）、`小于x` / `<x`（`v < x`）、`大于等于x` / `≥x` / `>=x`（`v ≥ x`）、`小于等于x` / `≤x` / `<=x`（`v ≤ x`）。
8. **US-08 限值行不参与比对**：作为报告员，校验时不会把限值行上的表达式或标记本身当成数据去比；数据区从限值行之下（及既有表头之下）起算。
9. **US-09 非数字跳过**：作为报告员，数据区空单元格、无法解析为普通数字的文本不标超限、不阻断通过判定（与现逻辑一致）。
10. **US-10 结果提示**：作为报告员，无超限格时出现与现有一致的短暂「校验通过」提示；有超限时超限格红字 + tooltip「数据超限」，并弹出需确认的失败摘要（行号列表形态与现有一致）。小数位不一致着色逻辑仍可与超限着色并存。
11. **US-11 预览始终含限值行**：作为报告员，只读预览里始终能看到限值行（若表中有），与勾选无关。
12. **US-12 报告勾选默认关**：作为报告员，限值行旁「报告中显示限值行」默认不勾；不勾时 Word 导出该表不含限值行；勾选后本次导出含限值行。
13. **US-13 勾选不落盘**：作为报告员，关闭试验明细或重开后，勾选恢复默认（不勾）；不写入 `DataTableRef` / `project_state.json`。
14. **US-14 单限值跨列居中（展示）**：作为报告员，整行仅一格有效限值且该行会显示（预览始终；Word 仅勾选时）时，展示为跨数据列居中，不修改磁盘 xlsx 的合并。
15. **US-15 导入样品编号保住限值**：作为报告员，表中已有限值行时，导入样品编号只把限值行之上的表头带并成「样品编号」，限值行仍在样品编号带下一行且 A 列（样品列）保持「限值」；样品 id 从限值行之下开始写入。
16. **US-16 无限值行导入照旧**：作为报告员，表中无限值行时，导入样品编号行为与改前一致。
17. **US-17 与模版无关**：作为报告员，校验只认当前附件快照里的限值行；模版是否预置限值行不影响按钮逻辑（预置只是方便带入内容）。

## Implementation decisions

* **测试缝（唯一）**：继续加深 `src/io/data_tables.py`——限值行定位、表达式解析、按限值标超限格、导入样品编号在有限值行时的表头/写入起点、按「是否含限值行」产出供 Word 使用的展示快照（含单限值跨列居中的合并描述）。UI 与 `word_engine` 只消费该缝 + 会话态勾选参数。
* **限值行标记**：样品列（预览第 0 列 / 工作表第 1 列）单元格去空白后等于「限值」即认定该行；不认位置猜测。
* **数据区**：比对跳过样品列、表头带、限值行；空与非数字跳过。
* **表达式**：区间分隔符为 `～`（全角波浪线）；不解析单位；非法/空表达式视为该列无限值（跳过）。
* **单格整表**：限值行上，除标记列外恰好一个非空单元格含可解析表达式 → 全表数据列共用；≥2 个非空可解析格 → 按列；0 个 → 等同无限值可用规则但无列可校（点按应全部通过或与「无限值列」等价——实现取「无超限 → 通过」）。
* **旧 API**：列校验按钮与 `_prompt_data_range_limits` 手工弹窗移除；`find_out_of_range(lo, hi)` 可保留给内部/测试或改为由限值驱动的新入口调用。
* **勾选**：会话态，按表（如按 `relative_path`）记在明细 UI；默认 `false`；导出调用缝时传入 `include_limit_row`。
* **Word**：`include_limit_row=false` 时导出快照去掉限值行；`true` 时保留，单限值行用展示用跨列合并居中，不写回 xlsx。
* **表头推断**：限值行不算可分页重复的 Word 表头行；`infer_header_row_count` / 导出表头重复范围需排除限值行（或先裁剪再推断）。

## Testing decisions

* **缝**：仅测 `src/io/data_tables.py`（无 UI、不启 Word/Excel）。
* **覆盖**：
  * 定位：有/无「限值」标记行。
  * 解析：`a～b`、负数区间、大于/小于/大于等于/小于等于及符号别名；非法串 → 该列跳过。
  * 按列 vs 单格整表共用。
  * 超限坐标；限值行自身不被 flag；样品列与非数字跳过。
  * `include_limit_row` 真/假时展示快照行集合；单限值时合并描述跨数据列。
  * 导入样品编号：有限值行时标记保留、id 写在限值行下；无限值行回归旧行为。
* **Done**：US-01–17 在缝上可测部分全绿；UI 按钮/勾选/提示与 Word 勾选行为人工或薄集成可验，但不作为缝的单测义务。

## Out of scope

* 把勾选写入项目 JSON / `DataTableRef`。
* 改写 xlsx 内限值行的合并单元格以做跨列居中。
* 限值带单位、科学计数法、`x-y` 半角连字符区间（本期只认 `～`）。
* 自动在无标记时「猜」限值行；模版库批量灌限值的管理 UI。
* 校验失败拦截试验完成勾或报告导出。
* 程序内编辑限值格（仍外开 Excel）。

## Further notes

* 词汇见 `CONTEXT.md`：**限值行**、**数据校验**。
* 现有小数位不一致检测与超限着色叠加方式保持；本期不改小数位规则。
* 刷新后根据新快照重算按钮可用态；Excel 改限值后须先刷新再校验（与现有预览一致）。

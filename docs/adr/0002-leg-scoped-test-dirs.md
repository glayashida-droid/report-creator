# 2. 试验目录按 Leg 前缀强关联

## Status

Accepted — supersedes ADR-0001 中「删试验卡片不删试验目录」及路径「与试验名完全同名、同名共用」的后果说明；照片仍以磁盘为真相（ADR-0001 其余部分继续有效）。

## Context

试验目录若只按试验名定位，不同 Leg 上的同名试验会共用一个文件夹；删卡片又留盘，卡片与目录容易脱钩。系统尚未上线，无需兼容旧的纯试验名目录。

## Decision

试验目录路径为 `3.测试组/{leg_name}-{试验名}/`（例：`Leg 1-温湿度试验`）。卡片显示名仍为试验名。第一次建照片夹或添加数据表时挂钩；此后改中文名则改目录，目标已存在则失败并回滚卡片名。删试验卡片或整条 Leg 前确认，确认后删除对应已挂钩目录；取消则整次不删。同一 Leg 内试验名不可重复；跨 Leg 允许同名。不做旧目录自动迁移。

## Consequences

导出、照片、数据表附件均须按同一路径公式解析。ADR-0001 的「取消明细不回滚照片」仍然成立。

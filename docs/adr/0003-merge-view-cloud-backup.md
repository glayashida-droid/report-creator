# 3. 合并视图：正式相册 + 公盘备份为真相

## Status

Accepted — extends [ADR-0001](0001-photos-live-on-disk.md)：照片清单仍不进 JSON；合并视图下「真相」扩展为本地正式相册路径与公盘同相对路径的联合。路径公式仍受 [ADR-0002](0002-leg-scoped-test-dirs.md) 约束。

## Context

仅以本地镜像为真相时，夜间上传并清本地大文件后，界面与导出会丢图。公盘已有权威备份时，需要在不把照片清单写入 JSON 的前提下，同时看到公盘已有图与本地新图，并支持删除进 `备用/` 而非软删表。

## Decision

- **合并视图**：列表、预览、导出经 `project_assets`（本地根 + 公盘根）解析；同一相对路径本地优先；仅公盘有则云标记。UI / Word **不得**手写双根分支。
- **备用**：删除 = 移入试验目录下 `备用/`；正式相册与导出排除；可拖回还原；不引入 JSON `photo_exclusions`。
- **JSON**：仍不存照片列表；`project_state.json` 保存时即时上公盘，与夜间大文件上传分离。
- **目录骨架**：清本地原文件后保留空目录，供白天继续写入。

## Consequences

换机或清本地后，只要公盘可达即可见云图并导出；他人加载同一项目可读最新 JSON 排期，照片滞后到对方夜间上传完成可接受。取消明细仍不回滚已改磁盘的照片操作（ADR-0001）。

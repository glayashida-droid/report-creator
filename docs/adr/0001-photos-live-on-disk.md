# 1. 试验照片以磁盘为真相

## Status

Accepted

## Context

试验明细弹窗有「保存 / 取消」，其它字段写入 `project_state.json`。照片需要在本地 `3.测试组` 里镜像，并在界面里增删、预览。若把照片清单存进 JSON，就要和磁盘做双向同步，取消弹窗时还得回滚拷贝。

## Decision

照片只存在 `data/{项目号}/3.测试组/{试验名}/{照片文件夹}/`。新建、拖入、删除、全部重命名立刻改磁盘；明细「取消」不撤回这些操作。项目 JSON 不存照片列表，打开明细时按目录扫描。

## Consequences

界面与导出共用同一套目录扫描。不能靠取消弹窗撤销刚整理的图。删试验卡片不删试验目录，避免误删文件。

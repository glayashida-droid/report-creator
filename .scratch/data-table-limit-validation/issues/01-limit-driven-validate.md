# TKT-1: 限值驱动数据校验

labels: `ready-for-agent`

## Parent

[docs/specs/data-table-limit-validation.md](../../../docs/specs/data-table-limit-validation.md)

## Demo path

打开带「限值」行的数据表预览 → 工具栏只有「数据校验」、列头无逐列「校验」、无「整表数据校验」与上下限弹窗 → 有限值行时可点，按表内表达式标超限红字或通过提示 → 在 Excel 删掉限值行并刷新 → 按钮低亮不可点。

## Objective

用表内 **限值行** 驱动一次自动比对，取代手动输入上下限的列校验与整表校验；缝上可单测识别、解析与标超限。

## Requirements

* 去掉列头「校验」按钮、「整表数据校验」及 `_prompt_data_range_limits` 手工弹窗；工具栏单一「数据校验」。
* 样品列文本为「限值」则认定限值行；无该行 → 按钮不可用；有则可用（与模版是否预置无关，只认当前快照）。
* 解析表达式：`a～b`（含负数）、`大于`/`>`、`小于`/`<`、`大于等于`/`≥`/`>=`、`小于等于`/`≤`/`<=`；不带单位；非法/空 → 该列跳过。
* 多列有可解析表达式 → 按列校验；除标记列外恰一格可解析 → 全表数据列共用；0 格可解析 → 点按无超限 → 通过。
* 比对跳过样品列、表头带、限值行本身；空与非数字跳过。
* 结果提示与现有一致（通过短提示 / 超限红字+tooltip+失败摘要）；可与小数位不一致着色并存。
* 缝：`src/io/data_tables.py` 提供定位、解析、按限值标超限；UI 只消费缝 + 预览快照。

## Acceptance Criteria

* [x] 列头无「校验」；无「整表数据校验」与手动上下限弹窗；仅有「数据校验」。
* [x] 无限值行时按钮不可用；有限值行时可点且不弹输入框。
* [x] 按列 / 单格整表共用 / 区间与单向开闭语法行为符合 SPEC；限值行与非数字不被标超限。
* [x] 通过与超限提示形态与改前一致。
* [x] `data_tables` 模块测试覆盖识别、解析、标超限；基线红、合并后绿。

# TKT-6: 试验明细弹窗与基础库联动 (Test Detail Dialog & DB Linking)

## 目标 (Objective)
为 Leg 图中的每个试验卡片开发详细配置的弹窗，并打通与本地标准库、设备库的下拉联动。

## 需求 (Requirements)
*   点击试验卡片（或卡片上的编辑按钮），弹出明细配置 Dialog。
*   **Dialog 内容**：
    *   试验起止日期选择控件。
    *   **标准下拉框**：绑定 TKT-2 提取的标准库数据。选中后，后台关联其标准描述和评价要求。
    *   **设备下拉框**：绑定 TKT-2 提取的设备库数据。
    *   **样品与结果**：可以增加行，人工录入样品编号字符串，并带有下拉或单选 (Pass/Fail)。
*   点击“确定”保存时，对日期进行合法性验证（不得超出主界面设置的全局项目日期范围），通过后将明细数据更新至当前节点状态中。

## 测试/验收标准 (Acceptance Criteria)
*   [x] 打开弹窗，标准库和设备库下拉列表有真实的 Excel 数据。
*   [x] 输入样品 A01 选 Pass，A02 选 Fail，点击确定保存。再次打开该节点，数据回显正确。
*   [x] 输入错误日期点击保存被拒绝并给予提示。

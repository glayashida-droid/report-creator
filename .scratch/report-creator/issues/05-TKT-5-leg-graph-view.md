# TKT-5: Leg 图绘制与交互视图 (Leg Graph View)

## 目标 (Objective)
在主界面实现核心的可视化交互区：可动态添加/删除横向 Leg 和纵向串行试验的网格（或嵌套列表）视图。

## 需求 (Requirements)
*   在主界面核心区域，实现一个可以横向滚动的区域。
*   提供 `+ 添加 Leg` 按钮：点击后增加一列（代表一组样品组试验线）。
*   在每一列底部提供 `+ 添加试验` 按钮：点击后在该列下方新增一个空的“试验卡片”。
*   每个“试验卡片”必须包含一个下拉选框（数据源绑定为候选池）。
*   任何对于界面的增删改，都必须同步反映到 TKT-1 定义的 Project State 对象中。

## 阻塞依赖 (Blocked by)

## 测试/验收标准 (Acceptance Criteria)
*   [x] 可以在界面上添加出 Leg1, Leg2, Leg3。
*   [x] 可以在 Leg1 下方添加 3 个试验框，Leg2 下方添加 2 个试验框。
*   [x] 下拉框能够正确选中候选池里的试验。
*   [x] 点击保存按钮能将当前的排布拓扑成功序列化为 JSON 落地。

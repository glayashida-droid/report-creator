# 中英文报告导出与编辑语言

labels: `ready-for-agent`

## Problem statement

中文报告导出已基本可用，但导出对话框里的「英文」「中英文」仍未接通：对应模板已有（`template_en` / `template_ze`），申请单解析也已拆出中英字段，标准库与设备库亦有英文列，却没有在界面里确认英文内容、也没有按语言填进 Word。报告员不能只核中文就盲导英文或中英文对照稿。

## Solution

把**编辑语言**与**导出语言**拆开：

- **编辑语言**（总开关，仅中文 | 英文）：放在「项目定位」里，收窄路径框后挤入切换控件。切换后概览与试验明细展示/编辑对应语言侧文案，两边各自持久化，导出前可核对英文。
- **导出语言**（中文 | 英文 | 中英文）：导出时仍弹窗三选一；按选项选用 `template_zh` / `template_en` / `template_ze`，用已确认的中/英文内容与固定对照标签生成报告。中英文导出是拼装，不做第三套「叠加编辑」界面，避免 UI 被长文撑坏。

缺英文时：英文报告留空（不回退中文）；中英文报告只出中文。申请单中文行若本身是纯英文/数字（无汉字），可当作英文侧取值。

## User stories

1. **US-01 编辑语言开关**：作为报告员，在「项目定位」中路径输入框旁，我能看到「中文 | 英文」切换；路径框比现在短，切换控件与「加载项目」等按钮同一行放得下。
2. **US-02 编辑语言独立于导出**：作为报告员，切换编辑语言不会改导出弹窗的默认选项；导出时仍从「中文 / 英文 / 中英文」三档里选。
3. **US-03 申请单双语文档入库**：作为报告员，加载/重载申请单后，委托方与地址的中英文（含报告抬头优先规则下的中英文）、样品信息各字段的中英文候选均写入项目状态；概览随编辑语言显示对应侧。
4. **US-04 申请单字母数字作英文**：作为报告员，当某字段中文行内容本身不含汉字、仅为英文或数字（如型号、车型）时，英文编辑态与英文/中英文导出可将该内容用作英文侧；若含汉字且无单独英文，则英文侧按缺英规则处理。
5. **US-05 概览随编辑语言切换**：作为报告员，切到英文时，概览中委托方/地址/样品相关字段显示英文侧（可空、可手改）；切回中文显示中文侧；两侧改动分别保存。
6. **US-06 明细条件/评判/结果描述双语**：作为报告员，选中标准后，中文侧载入标准库中文列（标准描述 / 评价要求 / 结果描述），英文侧载入对应英文列（`condition` / `Evaluation requirement` / `result`）；编辑语言切换时明细里展示当前侧，均可编辑并写入项目状态。
7. **US-07 关键参数双语替换**：作为报告员，关键参数仍是数字/字母；确认后用同一组确认值，分别对中文标准描述原文与英文 `condition` 原文各替换一遍，写入两侧条件正文。取消确认则两侧回到各自库原文。
8. **US-08 设备名称双语**：作为报告员，选择设备后保存中文名称与设备库 `Equipment` 英文名；编辑语言为英文时列表/已选显示英文名（缺则空）；导出时按导出语言取用。
9. **US-09 结论显示随编辑语言**：作为报告员，在英文编辑态，样品结论选项/显示为 Pass / Fail / N/A；中文编辑态仍为合格 / 不合格 / N/A；底层枚举不变，仅展示与导出映射不同。
10. **US-10 Leg 图与候选池不切语言**：作为报告员，切换编辑语言时，Leg 卡片试验名与报价/模板候选池仍保持中文（或原卡片名）；报告里「检测项目」的英文来自已选标准的标准库 `test item`，不要求改磁盘上的试验目录名或照片文件夹名。
11. **US-11 导出接通三模板**：作为报告员，选择「中文 / 英文 / 中英文」后分别使用对应 Word 模板生成报告，不再提示「模板未就绪」；报告编号后缀规则保持：中文 `…C`、中英文 `…E`、英文无字母后缀。
12. **US-12 中英文封面委托方**：作为报告员，导出中英文报告时，封面「委托单位 / 地址」用中文，「Customer / Address」用英文侧（含申请单字母数字特例与缺英只留中文行）；英文报告封面只出英文侧。
13. **US-13 样品信息表标签与日期**：作为报告员，样品信息表字段标签在中英文/英文报告中按 raw 对照方式输出（如样品名称Sample Name、客户送样数量…、样品接收日期Sample Received Date、样品检测日期Testing Period）；表下「由申请者提供并确认」在中英文报告含中英两句；未知中文键在中文报告原样，英文报告标签可空或仅出值，中英文报告缺英标签时只出中文标签。
14. **US-14 样品清单与结果汇总表头**：作为报告员，这两张表的表头在英文/中英文报告中为 raw 式中英对照（或英文报告纯英文）；检测项目列：中文用卡片试验名，英文用标准库 `test item`（多标准时按选定标准拼装规则与中文检测方法拼装一致的精神），中英文为 `中文 / 英文`；缺 `test item` 时英文侧留空、中英文只出中文名。
15. **US-15 汇总与明细结论**：作为报告员，中文报告结论为合格/不合格/N/A；英文报告为 Pass/Fail/N/A；中英文报告为 `合格 / Pass` 等形式（N/A 保持 N/A）。
16. **US-16 试验明细小标题与环境条件**：作为报告员，明细（1）～（8）小标题及「检测照片」等在英文/中英文报告中按 raw 固定中英（或纯英）表述；检测环境条件数值串固定为 `（23±5）℃，（50±25）%RH`，外层标签随语言。
17. **US-17 检测条件/评判/结果表正文**：作为报告员，导出使用项目里已保存的中/英文条件、评判与结果描述（非导出时再盲从库覆盖已编辑稿）；中英文报告按块中英对照输出（顺序与 raw 一致：先中后英或同行对照，与现有中文结构兼容）；数据表附件不翻译，按已有逻辑原样贴入。
18. **US-18 设备表**：作为报告员，设备表表头随语言；名称列用中文名、英文名或 `中文 / 英文`；型号、编号、校准有效期不强制翻译。
19. **US-19 照片说明**：作为报告员，照片文件夹名保持中文（试验前/试验中/试验后/数据），不改英文目录。导出时模版三夹默认说明：中文报告用试验前/试验中/试验后；英文用 Before test / Test setup / After test；中英文用对照形式。若我在拖入或随后把**图片文件**改成自定义名，则该图说明改用修改后的文件名（不含扩展名）；「数据」夹与自定义夹仍以文件名为主。
20. **US-20 文末法律说明**：作为报告员，法律与 CMA 备注以各语言模板内固定文案为准（模板已由人工维护），程序不动态拼长法律段。
21. **US-21 缺英规则**：作为报告员，英文报告某字段无英文则该处留空，绝不回退中文；中英文报告无英文则只出中文，不留空洞斜杠装饰（除非该处中文本身也空）。
22. **US-22 保存加载**：作为报告员，保存项目后再打开，编辑语言可恢复或默认中文，但中英文两套字段内容都在；切换编辑语言仍能看到先前确认过的英文。
23. **US-23 完成勾不受编辑语言影响**：作为报告员，完成勾仍只要求标准、关键参数确认、设备、样品等原规则；不要求英文侧非空才能打勾（避免无英文库行的项目无法导出中文报告）。
24. **US-24 导出范围与拦截不变**：作为报告员，全部 Leg / 单条 Leg / 单项试验范围与未完成拦截逻辑与中文版相同，三种导出语言共用。

## Implementation decisions

* **接缝 1（主）**：按 `report_language` 的 Word 导出——扩展现有报告生成入口；三选模板；首页、汇总、明细、照片说明、结论等全部随语言填好。无 UI 可用示例项目测三种语言。
* **接缝 2（辅）**：语言侧文案拼装纯函数——标签对照、结论映射、照片说明（相册中文名 → 说明）、申请单「无汉字则可用作英文」、中英文拼接（有英则 `中 / 英`，无英则仅中）。Word 引擎与（如需要）UI 取值共用，不测控件布局。
* **编辑语言 vs 导出语言**：编辑仅中文|英文；导出中文|英文|中英文。不做「中英文」编辑态叠加。
* **编辑开关位置**：「项目定位」行内；收窄路径输入；中文|英文切换紧挨路径与操作按钮之间（或同排合理空隙）。
* **状态**：项目状态同时持有中英文字段（申请单概览、标准条件/评判/结果描述、设备英文名等）；加载申请单时写入解析出的 `*_cn`/`*_en`，不再丢弃英文。
* **标准库英文列**：`test item`、`condition`、`Evaluation requirement`、`result`；选中标准时灌入英文侧；用户编辑后以状态为准导出。
* **设备库英文列**：`Equipment`；选择时一并记下。
* **关键参数**：同一组确认值分别替换中英文条件原文。
* **Leg / 试验目录 / 照片文件夹**：名称保持中文，不随编辑语言改名。
* **模板**：`template_zh.docx` / `template_en.docx` / `template_ze.docx`；法律与固定页眉页脚文案已在模板中维护；中英文封面 Customer/Address 值由程序填占位（或空单元格）。
* **样品信息标签**：按 raw 固定对照表映射已知键；日期行英文为 Sample Received Date / Testing Period。
* **报告编号**：沿用现有 `default_report_no` 规则。

## Testing decisions

* **好测试**：只断言对外行为（给定状态 + 语言 → 文案或生成文档中的可见字符串），不绑私有方法结构。
* **接缝 1**：扩展现有 Word 引擎测试——三种 `report_language` 选用模板意图、封面中英、结论映射、汇总检测项目英文、明细小标题、照片说明；缺英不回退（英文报告）/ 只出中文（中英文报告）。
* **接缝 2**：纯函数单测——结论、相册说明、无汉字申请单值、中英文拼接。
* **先验**：现有 `test_word_engine` 报告编号与中文导出；`application_parser` 中英拆分；标准库/设备库列读取。
* **Done**：示例项目可导出中文、英文、中英文三份；英文编辑态能看到并改英文条件/结果描述后出现在英文或中英文报告中。

## Out of scope

* 不为「中英文」做第三套编辑 UI 或只读对照预览窗（若以后要预览另开需求）。
* 不把 Leg 图、报价池、试验目录、照片文件夹改成英文名。
* 不翻译数据表附件内容。
* 不在程序里维护长篇法律条文（以模板为准）。
* 不重做纯英文申请单流程之外的沃尔沃等特例解析（沿用现有解析，只把英文侧接进状态与导出）。
* 不要求英文侧填满才能打完成勾或导出中文报告。

## Further notes

* 标准库/设备库个别行缺英文时，靠编辑态手补或接受英文报告留空。
* 多标准时 `test item` 与条件块的拼装顺序与现有中文多标准顺序一致。
* `template_ze` 封面 Customer/Address 值格若仍无占位符，导出时程序直接写入英文字符串。
* 照片「人工改名」指图片文件名（stem），不是照片文件夹名。

# TKT-4: 模版口子

labels: `ready-for-agent`

## Demo path
三选一选「模版」→ 从应用级 `templates/data_tables/` 列表选一份（若有）→ 复制进该试验数据表附件，列表标题为文件名；目录为空时入口可用但不崩溃（提示无模版或空列表）。

## Objective
留下模版目录与「选文件复制」入口；不做模版库管理、不做选模版后自动连带样品号（可用票 3 的导入样品编号事后补）。

## Requirements
* 模版根目录为应用侧 `templates/data_tables/`（非项目内）。
* 「模版」选项列出该目录下可用的 `.xlsx`；选中后复制到数据表附件并追加索引，标题为文件名。
* 目录不存在或为空时：不崩溃，给出空状态或提示。
* 不包含模版编辑/上传到模版库的管理 UI。
* 模块测试：从模版目录复制后附件与索引正确；空目录行为安全。

## Blocked by
* [01-free-edit-e2e.md](01-free-edit-e2e.md)

## Acceptance Criteria
* [ ] 目录中放一份模版 xlsx 后，可经「模版」加入列表，标题为该文件名，附件目录有副本。
* [ ] `templates/data_tables/` 为空或不存在时，选择「模版」不会导致程序崩溃。
* [ ] 模版复制的模块测试基线为红、合并后为绿。

## Note
与票 3 无阻塞关系；票 1 完成后可与票 2/3 并行。建议在票 3 之后做，便于复制后立刻用「导入样品编号」手测。

# TKT-3: 外开编辑 + 导入样品编号

labels: `ready-for-agent`

## Demo path
对已有数据表点「打开编辑」→ 本机 Excel（否则 WPS / 系统默认）打开该附件；点「导入样品编号」后第 2 行起写入当前样品表编号（第 1 列空则写第 1 列，有内容则左插一列）；再点刷新，预览能看到编号列。

## Objective
编辑走外置表格软件；程序侧提供打开与「导入样品编号」改盘，不内置伪 Excel。

## Requirements
* 「打开编辑」：优先 Microsoft Excel，其次 WPS，再次系统默认关联；均失败则明确提示。
* 「导入样品编号」：改该附件第一个工作表；第 1 列在数据区无内容则写入第 1 列，有内容则左侧插入一列再写；样品号取自当前明细样品表，从第 2 行起向下铺开（跳过表头）；不与样品表后续改动自动同步。
* 导入后不强制自动刷新预览，但用户可通过已有「刷新」看到结果（依赖票 2）。
* 外开逻辑可注入/可测命令解析，CI 不启动真实 Excel。
* 导入样品编号有模块测试（空列 / 已有内容插列 / 从第 2 行起）。

## Acceptance Criteria
* [ ] 「打开编辑」在有 Excel 或 WPS 的环境下能打开对应附件；都没有时有明确错误提示。
* [ ] 空表导入样品编号：编号出现在第 1 列，且从第 2 行开始。
* [ ] 第 1 列已有内容时导入：左侧多出一列样品号，原内容右移。
* [ ] 导入后点刷新，预览能看到新列/新值。
* [ ] 导入样品编号的模块测试基线为红、合并后为绿。

# TKT-1: 自由编辑打通（空簿 + 索引 + 列表）

labels: `ready-for-agent`

## Demo path
在试验明细「样品与结果」里点「添加数据表」→ 选「自由编辑」→ 输入标题 → 结果表下方列表出现该项；磁盘试验目录下出现「数据表附件」中的工作簿；保存项目后重开明细，列表仍在。

## Objective
打通数据表附件的第一条垂直路径：附件目录、空工作簿、试验节点上的数据表索引（随项目 JSON）、明细入口与列表。三选一弹窗先只把「自由编辑」做实；上传/模版可占位或禁用并指向后续票。

## Requirements
* 试验名可用时，才能在该试验下创建/使用「数据表附件」目录；不可用时入口不可用或明确提示（对标试验照片）。
* 「生成」右侧有「添加数据表」；每次点击弹出三选一。
* 「自由编辑」：自定义标题 → 在数据表附件目录新建空 xlsx → 索引追加一项（标题、路径、顺序）。
* 样品/结果表下方显示数据表列表（可多条，新表追加在末尾）。
* 索引随项目保存/加载；添加即落盘，明细「取消」不删除已写入的附件文件（与照片一致）。
* 同名文件冲突时自动加后缀、不覆盖。
* 无 UI 的数据表附件模块可单测：建目录、建空簿、索引字段读写。

## Blocked by
* None

## Acceptance Criteria
* [ ] 自由编辑一条数据表后，列表可见自定义标题，且附件目录中存在对应 xlsx。
* [ ] 保存并重新打开同一试验明细，列表仍显示该条。
* [ ] 无可用试验名时，无法创建数据表附件（或入口不可用）。
* [ ] 针对空簿创建与索引持久化的模块测试在基线上为红、合并后为绿。

# TKT-2: 上传 Excel + 抽屉预览 + 刷新

labels: `ready-for-agent`

## Demo path
三选一选「上传现有 Excel」→ 选文件 → 列表标题为文件名；展开该行嵌套抽屉看到只读预览（首表非空包围盒，盒内空单元格保留，合并可辨）；在外部改同一文件后点「刷新」，预览更新。

## Objective
接上上传路径与只读预览：复制进数据表附件、标题取文件名；列表项以嵌套抽屉（对标标准条件/要求那种抽屉中的抽屉）展示预览；显式刷新才重读盘。

## Requirements
* 「上传现有 Excel」可选 `.xlsx`，复制到该试验数据表附件目录；索引标题为文件名（无路径）。
* 预览针对第一个工作表的非空单元格包围盒，盒内空值保留；合并信息可读。
* 预览只读，非程序内编辑网格。
* 「刷新」按钮重读磁盘并更新预览；不自动监视文件变化。
* 可连续上传多张，均追加到列表。
* 模块测试：上传夹具 xlsx 后快照为包围盒且含空单元格；改文件再读快照变化。

## Acceptance Criteria
* [x] 上传后列表标题等于源文件名，附件目录中有副本。
* [x] 展开抽屉可见只读预览；包围盒内空白格不丢。
* [x] 外部修改附件后未点刷新则预览仍旧；点刷新后与磁盘一致。
* [x] 上传与刷新读盘的模块测试基线为红、合并后为绿。

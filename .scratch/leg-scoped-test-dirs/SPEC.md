# 试验目录 · Leg 前缀强关联

labels: `ready-for-agent`

## Problem statement

试验目录若只按试验卡片中文名定位，不同 Leg 上的同名试验会共用一个文件夹；删卡片又留盘，卡片与目录容易脱钩。报告员在 Leg 图上频繁改名、删节点时，担心照片和数据表附件对错目录或留下孤儿。需要变成：路径带所属 Leg、挂钩后强关联（改名/删除同步），且同一 Leg 内不允许同名试验。

## Solution

试验目录改为 `3.测试组/{leg_name}-{试验名}/`（例：`Leg 1-温湿度试验`）。卡片与报告「检测项目」仍只显示试验名。第一次建照片夹或添加数据表时挂钩；此后改中文名则改目录，目标已存在则失败并回滚。删已挂钩卡片或整条 Leg 前确认，确认后删对应目录；未挂钩则直接删结构、不弹盘确认。同一 Leg 内中文试验名不可重复（跨 Leg 允许）。系统未上线，不做旧纯试验名目录迁移。见 ADR-0002。

## User stories

1. **US-01 路径公式**：作为报告员，某试验在 `Leg 1` 上且中文名为「温湿度试验」时，其试验目录为 `3.测试组/Leg 1-温湿度试验/`（`leg_name` 原样 + 半角 `-` + 试验名）；卡片上仍只显示「温湿度试验」。
2. **US-02 跨 Leg 同名分夹**：作为报告员，`Leg 1` 与 `Leg 2` 都可以有名为「温湿度试验」的卡片；挂钩后分别对应 `Leg 1-温湿度试验` 与 `Leg 2-温湿度试验`，互不共用。
3. **US-03 懒挂钩**：作为报告员，我只在 Leg 图上建卡片并起名、尚未建照片夹或数据表时，磁盘上不出现该试验目录。
4. **US-04 建照片夹挂钩**：作为报告员，我在明细里首次按模版开四夹或自定义新建照片夹时，程序按路径公式创建（或使用）试验目录并写入照片夹。
5. **US-05 建数据表挂钩**：作为报告员，我在明细里首次添加数据表时，程序按同一路径公式创建试验目录下的「数据表附件」并落盘。
6. **US-06 手工改名跟目录**：作为报告员，卡片已挂钩后，我在 Leg 图上把中文名从 A 改成 B，试验目录从 `{leg_name}-A` 改名为 `{leg_name}-B`；数据表索引里的相对路径前缀一并更新。
7. **US-07 标准覆盖跟目录**：作为报告员，明细里选标准并保存后，卡片中文名被第一条标准的「试验名称」覆盖为 B；若进入明细前已提交名为 A 且已挂钩，则目录同样从 `{leg_name}-A` 改为 `{leg_name}-B`。
8. **US-08 改名冲突回滚**：作为报告员，改名目标目录 `{leg_name}-B` 已存在时，程序提示「同名试验项目已存在，请重新命名」，改名失败，卡片中文名回滚为改名前的名字，目录保持不动。
9. **US-09 未挂钩改名**：作为报告员，卡片尚未挂钩时改中文名只改卡片（及未落盘状态），不在磁盘上新建或移动目录。
10. **US-10 删已挂钩卡片**：作为报告员，删除一张已挂钩的试验卡片时，程序确认将同时删除对应试验目录（含照片与数据表附件）；我选「是」则删卡片并删目录；选「否」则整次取消，卡片与目录都保留。
11. **US-11 删未挂钩卡片**：作为报告员，删除尚未挂钩的试验卡片时，不弹与目录相关的确认，直接从 Leg 图移除该卡片。
12. **US-12 删整条 Leg（有挂钩）**：作为报告员，删除一条 Leg 且其下存在已挂钩试验时，程序一次确认并列出将删除的试验目录名；「是」则删除该 Leg、其下全部卡片及列出的目录；「否」则整次取消。
13. **US-13 删整条 Leg（无挂钩）**：作为报告员，删除一条 Leg 且其下没有任何已挂钩试验时，不弹与目录相关的确认，直接删除该 Leg 及其卡片结构。
14. **US-14 同 Leg 重名拦保存**：作为报告员，同一条 Leg 内两张卡片中文试验名相同时，保存项目被拦截并提示需修改；跨 Leg 同名不因此拦截。
15. **US-15 同 Leg 重名拦挂钩**：作为报告员，同一 Leg 内试验名不唯一时，不能为该名新建照片夹或添加数据表（提示后中止），避免歧义挂钩。
16. **US-16 导出读新路径**：作为报告员，生成 Word 时，试验照片只从该节点的 `{leg_name}-{试验名}` 试验目录下按既有相册规则读取，不再使用纯试验名路径。
17. **US-17 英文名不进目录名**：作为报告员，切换编辑语言或填写英文卡片名不改变试验目录名；目录名只随中文试验名与所属 `leg_name`。
18. **US-18 无可用试验名**：作为报告员，试验名不可用（空 / 占位 /「自定义」）时，不能挂钩（不能建照片夹或数据表附件目录），与现行为一致，仅路径公式在可用名时生效。

## Implementation decisions

* **ADR**：遵循 ADR-0002（试验目录按 Leg 前缀强关联）；ADR-0001 中「照片以磁盘为真相、取消明细不回滚」仍有效；「删卡片不删目录」与「纯试验名路径」作废。
* **路径公式**：目录名 = `{leg_name}` + `-` + `{中文试验名}`，其中 `leg_name` 为所属 Leg 当前字段原样（现为 `Leg 1`、`Leg 2`…）。落在 `3.测试组/` 下一层，不嵌套 Leg 子目录。
* **测试缝（主）**：试验目录 IO——解析路径、挂钩创建、改名、删除、改名冲突；与 GUI 分离。照片、数据表附件、导出贴图均经同一路径公式，禁止各处手写纯试验名目录。
* **测试缝（辅）**：项目状态上「同一 Leg 内中文试验名是否重复」；保存与挂钩前共用。
* **改名 API**：改名入参为（项目根、旧目录名或旧 leg+旧试验名、新 leg+新试验名）；目标已存在则失败，由 UI 提示固定文案并回滚卡片名。
* **删除 API**：提供删除整个试验目录（`shutil` 级移除）；仅在确认后、且调用方确认该目录对应该卡片/Leg 时调用。
* **确认文案**：删卡片须说明将删除试验目录及其中照片与数据表附件；删 Leg 一次列出将删目录名。默认倾向「否」/取消更安全。
* **数据表相对路径**：索引中的 `relative_path` 前缀随试验目录改名重写（既有 retarget 逻辑改为新公式）。
* **不做迁移**：不扫描、不自动把旧的 `3.测试组/{试验名}/` 改成带 Leg 前缀；新挂钩一律用新公式。
* **Leg 改名 / 跨 Leg 挪卡片**：当前 UI 不支持改 `leg_name`、也不支持把节点拖到另一条 Leg；本期不实现对应目录迁移。若日后支持，须同步改目录前缀。

## Testing decisions

* **好测试**：只断言可观察行为（路径字符串、目录是否存在/已改名/已删除、冲突是否抛错、同 Leg 重名是否检出），不绑具体控件布局。
* **主缝覆盖**：
  * 给定 `leg_name` + 试验名 → 试验目录 / 相册 / 数据表附件路径正确。
  * `rename`：源存在且目标不存在 → 目录改名成功；目标已存在 → 失败且源仍在。
  * `delete`：目录存在则移除；不存在则 no-op。
  * 导出/列表相册：只认新公式路径下的夹，不读纯试验名旧路径。
* **辅缝覆盖**：同 Leg 两张同名 → 判重；跨 Leg 同名 → 不判重；保存拦截与挂钩前拦截与该判定一致。
* **Prior art**：`tests/test_test_photos.py`（`rename_test_dir` 等）、`tests/test_data_tables.py`（路径与 retarget）、`tests/test_project_state.py`（`duplicate_test_names`）、`tests/test_leg_graph.py`（改名跟目录）。
* **Done**：新项目从建卡 → 挂钩 → 改名（含标准覆盖）→ 导出读照 → 删卡/删 Leg 确认后盘上目录消失；同 Leg 重名无法保存；跨 Leg 同名可保存且分夹。

## Out of scope

* 旧纯试验名目录的自动或向导迁移。
* 修改 Leg 标题（`leg_name`）或把试验卡片拖到另一条 Leg 时的目录迁移。
* 嵌套路径 `3.测试组/{leg_name}/{试验名}/`。
* 用 `leg_id`（如 `L1`）代替 `leg_name` 作为前缀。
* 英文试验名进入目录名。
* 「只删卡片、保留目录」的脱钩选项。
* 公盘原件的删除（仅本地镜像试验目录）。

## Further notes

* 词汇见根目录 `CONTEXT.md`：**试验目录**、**挂钩**、**同名试验（校验）**。
* 根 `SPEC.md` 的 US-04 / US-10 及「试验照片」实现决策仍写纯试验名与「删卡片不删目录」，实现本变更时应同步改掉，避免双源真相。
* 数据表规格里「删卡片不删目录」的范围外说明被本变更覆盖：删已挂钩卡片/Leg 时级联删除整个试验目录（含数据表附件）。
* 改名失败固定提示：「同名试验项目已存在，请重新命名」。
* 同 Leg 重名保存提示可沿用或改为明确「同一 Leg」；实现时与辅缝文案一致即可。

## Agreed seams (binding)

| Seam | Responsibility | Tested behaviors |
|------|----------------|------------------|
| 试验目录 IO（扩展既有照片 IO） | 路径公式、挂钩创建所用根路径、改名、删除 | 路径、`rename` 成功/冲突、`delete`、列表/导出只认新路径 |
| 同名校验（项目状态） | 同一 Leg 内中文试验名是否重复 | 同 Leg 重名 / 跨 Leg 同名；供保存与挂钩前使用 |

UI（Leg 图删除确认、明细挂钩按钮）与 Word 引擎不是测试缝，只消费上述行为。

Report Creator 更新记录
========================

Ver 1.0  (2026-08-14)
- 窗口标题显示 Report Creator---Ver1.0  Design by IKARUGA
- 试验卡片：编辑明细与删除按钮同高；选择框与「编辑明细 + x」等宽
- 标准、设备、样品结果均填写后，试验名称右侧显示完成勾
- Leg 卡片按内容收缩，靠左上排列，不再撑满排布区
- 表头批量结果下拉贴着「测试结果」，生成样品后位置保持正确
- 明细对话框支持标准 / 设备 / 样品结果维护
- 项目路径加载、导出目标选择与深色主题

Ver 1.1  (2026-08-14 晚)
- Leg 图可保存为跨项目模板（弹窗命名），存入 data/leg_templates/，不进项目镜像
- 模板只带布局、试验名、标准及随标准填充的条件/描述；不带设备、样品、结论、日期
- 导入模板只替换 Leg 图，报价池与申请单不动；已有 Leg 图或同名模板会先确认覆盖
- 左侧候选池增加「报价单 / 模板」开关；两池独立，不做名称对齐或合并
- 试验下拉从两池并集挑选（字面相同只显示一次）；选完后可在框内手工改名
- 导入后试验框自带名字，仍可增删；改完的图可再存成模板
- SPEC 同步 US-08 / US-09 与双池规则

Ver 1.1.1  (2026-08-17)
- 导入模板后试验可编辑明细（不再因标准库未挂上而点了没反应）
- 候选池按每个试验名自身宽度换行，长名字不再撑开或裁成省略号
- 测试设备按设备编号回填，同名设备不会被全部勾上
- 已选标准 / 设备摘要显示在抽屉标题右侧，展开行不再重复
- 标准可多选并按勾选顺序写入条件、评判与结果描述；报告按标准分列结果
- 设备校准过期在名称上标红；保存 / 加载入口改称「项目」

Ver 1.1.2  (2026-08-17)
- 标准库「关键参数」需在检测条件抽屉确认后，才从原文替换进条件正文
- 取消确认回到原文，再确认始终从原文替换，不会残留上一次的值
- 有关键参数未确认时，试验卡片不打完成勾；导出范围内未打勾则拦截
- 模板只存标准身份，导入后从活库灌入正文，关键参数需重新确认
- 检测条件 / 评判要求 / 结果描述不再重复标准号和章节号，只保留试验名称
- 标准库文件改过后再打开明细会重新读取

Ver 1.2  (2026-08-18)
- 明细增加「试验照片」抽屉：只认 `3.测试组/{试验名}/` 下一层文件夹里的 jpg/png，磁盘为真相，不写入项目 JSON
- 可按模版一次开出试验前 / 试验中 / 试验后 / 数据，或自定义新建；从访达拖入图片或一层文件夹即拷贝
- 整批重命名可选文件夹名、项目号或自定义前缀，序号三位补零；「全部重命名」按拍摄时间从 001 重编
- 改试验名时同步改试验目录（目标已存在则拦住并恢复原名）；删卡片不删目录
- 导出只读该试验的照片文件夹（模版四夹固定在前），不再模糊匹配其它目录，也不贴试验目录根下散图
- 试验照片不参与完成勾；试验名可在下拉框内直接输入（无需「自定义」弹窗）
- 关键参数输入与确认改为品红强调
- 导出栏收成一行，模式标签缩短，仅按 Leg 选目标
- 项目定位：「加载」改称「加载项目」并与「选择目录…」对调；新增「重载申请单」一键恢复误删的项目信息字段（不清空其它内容）
- 样品与结果改为三列（编号 / 结果描述 / 结论），描述随标准带入；Word 检测结果表同步三列
- 试验照片拖入可选保持原文件名；双击缩略图可改单个文件名
- 右侧支持「甘特图」视图切换与缩放；接收/开始/结束日期可留空
- 「项目概况」改称「项目信息」，「Leg 图排布区」改称「项目明细」

- 试验照片按相册排版：前/中/后两图并排，「数据」单列加宽；嵌入分辨率对齐金样
- 取消再勾选同一标准时保留关键参数确认与会话内编辑，完成勾不丢
- 多标准 Word：每个标准单独一张样品编号 / 试验结果 / 试验结论表，表间空一行；检测条件正文前加试验名并缩进两格

- 编辑语言支持中文 / 英文切换；项目信息与明细标签跟编辑语言走，与报告字段措辞对齐

- 样品信息表「检测日期」只取项目信息日期栏，不再从试验节点推断
- 未选定试验名时禁用「编辑明细」；「保存/加载项目」改称「保存/加载明细」
- 路径区：「从路径加载项目」「选择项目」；长路径显示起点；日期栏 yyyy.MM.dd，文案对齐申请单/报告
- 从访达拖入试验照片后强制窗口前置；从前置试验导入样品只拷贝编号，保留本试验结果描述与结论

- 改试验名时同步改写数据表附件相对路径

Ver 1.3  (2026-08-28)
- 公盘数据源：`config.json` 配置设备清单、标准库、Leg 模板、报告模板与数据表模版路径；顶部显示连接状态并后台定时探测
- 标准库 / 设备清单 / 报告模板 / Leg 模板 / 数据表模版改从公盘读取；未就绪时拦截开明细、导模板与 Word 导出
- Word 导出前确认报告编号；文件名以编号命名，重名可选覆盖或 `-2` 后缀
- 标准库试验环境条件写入 Word 检测条件；数据表表头识别更智能
- Word 结果汇总表增加「检测时间」列；表头中英文分行显示
- 关闭窗口时未保存提示；保存成功弹窗自动关闭
- 甘特图：拖拽超出项目日期范围时拦截并恢复；调整起止边时只动一侧；左侧长标签省略号 + 悬停显示全名
- Leg 卡片固定 220px 宽；完成勾占位不撑宽；试验名下拉左对齐、悬停显示全名
- 「打开」与导出后定位文件支持 Windows 资源管理器
- 新增 `windows-deploy/`：Windows 首次部署与更新脚本
- Windows 部署：setup/update 分步检查路径并输出诊断；失败可先跑 `test_paths.bat` 截图排查
- 安装目录改为弹窗自选，禁止选到盘符根目录；文件夹路径经临时文件回传，避免空路径导致同步失败
- 依赖优先 Python 3.12（与 3.10/3.11 并存、不卸载旧版）；`windows-deploy/wheels` 预置离线包，缺包才联网
- 桌面快捷方式与 `run.vbs` 启动，不再弹出黑色命令行窗口
- 部署脚本窗口改为英文，避免中文 Windows 编码乱码；说明见 `windows-deploy/使用说明.txt`
